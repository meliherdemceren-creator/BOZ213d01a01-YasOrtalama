
# Yaş ortalaması hesaplama
Bu program yaşları bilinen 3 kişinin yaşlarının ortalamasını bulmayı sağlar
1. Grubun yaş ortalamasını hesaplar
2. Gruptaki en büyük kişiyi bulur
3. Gruptaki en küçük kişiyi bulur
# Kullanılan değişkenler ve değerleri ve açıklamaları
1. sadef_yas - 19 - Sadef'in yaşını gösterir
2. enes_yas - 20 - Enes' in yaşını gösterir
3. muharrem_yas - 21 - Muharrem' in yaşını gösteriri
4. toplam_yas - 60 - Bu 3 kişinin yaşları toplamını ifade eder
5. ortalama - 20 - Bu 3 kişinin toplam yaşlarının kişi sayısına bölümünü verir
# Kullanılan fonksiyonlar ve koşullu durum idadeleri 
1. print (ortalama) : verilen değişkeni ekrana yansıtır
2. if : bir koşuldur ve şart sağlanırsa çalışır
3. elif : ilk if yanlışsa başka şartla tekrar kontrol eder
